# Promote accepted findings

Arguments: $ARGUMENTS. Load `research-studio:study-synthesis` and follow its **Promote accepted
findings** mode exactly: only ticked to-dos, Draft and Proposed statuses, Source ref "ST-n F#".
Then list what was created, with links, and remind the user that only they set Accepted.
