# Inclusive Design Audit Checklist
*Based on Holmes (Mismatch) and Microsoft Cognitive Guidebooks*

## 1. Sensory Mismatches
- [ ] **Vision:** Is information conveyed by color alone? (Exclude: Colorblindness)
- [ ] **Hearing:** Is audio content captioned? (Exclude: Deaf/Situational Silence)
- [ ] **Touch:** Are touch targets at least 44px/9mm? (Exclude: Tremors/Situational "Fat Finger")

## 2. Cognitive Exclusion
- [ ] **Attention:** Are there moving elements that cannot be paused? (Exclude: ADHD/Vestibular)
- [ ] **Memory:** Does the flow require remembering a code from a previous screen? (Exclude: Short-term memory loss/Stress)
- [ ] **Language:** Is the reading level above Grade 8? (Exclude: Cognitive impairment/Non-native speakers)

## 3. Mental Health Impact
- [ ] **Anxiety Trigger:** Are there countdown timers or "scarcity" warnings? -> *Action: Remove or allow extension.*
- [ ] **Control:** Is it easy to cancel/undo a subscription or critical action? -> *Action: Add "Undo".*
- [ ] **Safety:** Can the user "Preserve" their work if they need to step away abruptly? -> *Action: Auto-save.*
