# Cognitive & Emotional Models

## 1. The Bottlenecks Framework (Evans)
*Innovations must survive these filters to be adopted.*

### Attention (Foveal Acuity)
* **Task-Positive Mode:** Goal-seeking. User has tunnel vision. **Rule:** Suppress all interruptions.
* **Task-Negative Mode:** Browsing. Open to stimulus. **Rule:** Enable discovery.
* **Attentional Desert:** In LTR interfaces, the bottom-right is a dead zone. Never place "Next" or "Submit" there without heavy weighting.

### Perception & Memory
* **Precognitive Guessing:** Users act on shape/color before reading.
* **Working Memory:** Limited capacity. Externalize all rules; do not force memorization.

## 2. Emotional Design Hierarchy (Walter)
*Critique methodology for feature prioritization.*
1. **Functional:** Solves the problem.
2. **Reliable:** Data integrity/Uptime.
3. **Usable:** Low friction.
4. **Pleasurable:** Personality. *Only address this after 1-3 are solved.*

## 3. Miller's Law (Working Memory)
*Source: George Miller (1956)*
The average person can hold **7 ± 2 items** in working memory at once.
* **Application:** Navigation menus, form fields, option lists — group into chunks of 5-9.
* **Chunking:** Turn 10 unrelated items into 3-4 meaningful groups (e.g., phone numbers: 555-867-5309, not 5558675309).
* **Design Rule:** If a user must compare more than ~4 options simultaneously, provide a comparison tool. Don't rely on memory.

## 4. Gestalt Principles of Perception
*Source: Wertheimer, Koffka, Köhler*
The brain groups visual elements automatically. Use this to create structure without adding chrome.
* **Proximity:** Elements close together are perceived as a group. Use spacing to create hierarchy — not boxes or dividers.
* **Similarity:** Elements that look alike (color, shape, size) are perceived as related. Consistent styling = implicit grouping.
* **Closure:** The brain completes incomplete shapes. Progress bars, partially visible cards, and cropped images all exploit this.
* **Common Region:** Elements inside a shared boundary are grouped. Cards, panels, and modals work because of this.
* **Continuity:** The eye follows smooth paths. Align elements along a clear visual line.

## 5. Gulf of Execution & Evaluation (Norman)
*Source: Don Norman — The Design of Everyday Things*
Two gaps between user intent and system feedback:
* **Gulf of Execution:** "How do I do what I want?" — Reduce by making actions visible and discoverable.
* **Gulf of Evaluation:** "Did it work?" — Reduce by providing immediate, clear feedback on state changes.
* **Design Rule:** If a user has to ask either question, there is a gulf to bridge.

## 6. Involvement & Coping (Turner)
* **Practical Coping:** Good UX is "invisible." The tool should disappear (like a hammer in a carpenter's hand).
* **Affordances:** Are relationships, not properties. A button only "affords" clicking if the user has the ability to perceive and reach it.
