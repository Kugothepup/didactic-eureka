# Persuasion Mechanics & Behavioral Economics

## 1. The Dual-Process Model (Thinking Fast and Slow)
*Source: Kahneman / Mittelstaedt*
Users operate in two cognitive modes. Design must target the correct one.
* **System 1 (Fast):** Intuitive, emotional, subconscious.
    * *Design Target:* Visual hierarchy, "Gut feel," aesthetics, defaults.
    * *Trigger:* "Buy Now," color cues, simple icons.
* **System 2 (Slow):** Logical, calculating, conscious.
    * *Design Target:* Comparison tables, detailed specs, reviews.
    * *Trigger:* High-risk decisions (e.g., mortgages), "Compare," complex forms.
* **The Rule:** Don't force System 2 thinking for a System 1 task (e.g., don't ask for complex registration to browse a meme site).

## 2. Nudge Theory & Choice Architecture
*Source: Thaler & Sunstein / Behavioral Economics*
How choices are presented dictates what users choose.
* **Defaults:** The most powerful nudge. Users rarely opt-out.
    * *Ethical Use:* Set the default to the most beneficial option for the user (e.g., "Save paper" checked by default).
* **Decoy Effect (Asymmetric Dominance):**
    * *Mechanism:* Adding a 3rd "ugly" option makes the target option look better.
    * *Example:* Small ($3), Large ($7), and "Large + Cookie" ($7.50). The middle option pushes users to the bundle.

## 3. Core Cognitive Biases in UX
* **Anchoring:** The first number seen sets the baseline value.
    * *Application:* Show the "crossed out" high price ($100) next to the real price ($50).
* **Scarcity:** Fear of Missing Out (FOMO).
    * *Mechanism:* "Only 2 left at this price."
    * *Warning:* Artificial scarcity destroys trust. Only use if true.
* **Social Proof:** "Others are doing it."
    * *Application:* "Most Popular," "500 people viewed this today."
* **Loss Aversion:** The pain of losing $10 is greater than the joy of gaining $10.
    * *Application:* Frame messages as avoiding loss ("Don't lose your progress") rather than gaining benefit ("Save your work").

## 4. The Ethics of Influence
*Distinguishing between Nudges and Dark Patterns.*
* **The Nudge (White Hat):** Aligns the user's behavior with their *own* stated goals (e.g., a fitness app reminding you to run).
* **The Sludge (Gray Hat):** High friction to prevent an action (e.g., "Roach Motel" cancellation flows).
* **The Dark Pattern (Black Hat):** Deception. Tricking the user into an action they did not intend (e.g., sneaking an item into the cart).
* **Audit Question:** "If the user knew exactly how we designed this, would they feel helped or manipulated?"
