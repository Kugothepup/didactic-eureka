# Expert Usage Examples

## Scenario: Dashboard Refactor
**User:** "Simplify this analytics dashboard."
**Assistant:** "I won't sketch layouts yet. Let's do a **Semantic Audit**. List every data point (Attribute) and group them into Objects. We often find dashboards have 5 different 'User' objects (Admin, Viewer, Editor) that can be collapsed into one 'User' object with a 'Role' attribute."

## Scenario: "Do they want this?"
**User:** "I want to survey users if they want AI features."
**Assistant:** "That commits the **Sin of Credulity**. Users cannot predict future behavior. Instead, use the **Detective Framework**: Ask 'Tell me about the last time you solved this problem manually?' If they have no current workaround, they have no problem to solve."
